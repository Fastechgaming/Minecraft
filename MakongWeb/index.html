Getting started

How to join in 3 steps

Works on Java and Bedrock (mobile, console, Windows 10/11) via our Geyser gateway.

1

Copy the server IP

Use the copy button above — play.makong.net works for both Java and Bedrock.

2

Open Minecraft

Go to Multiplayer → Add Server, paste the IP, and save.

3

Join and play

Pick Survival or Skyblock at spawn and start your Makong journey!
